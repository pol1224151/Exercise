帳號與設定

1. 讀入帳號

先把角色和裝備放進來。還沒有這份帳號時，不會給選角。

  1. 打開 Fribbels Epic 7 Optimizer。在 Importer 開始掃描，進到大廳，停止掃描，存成 gear.txt，再按 Merge。
  2. 同一個 Importer 頁按 Save all optimizer data，存成 JSON。這份才有面板、神器和刻印。
  3. 選擇那個 JSON 或 gear.txt，或把內容貼進下面的框再按「用框裡的內容」。

還沒有帳號。

讀入後存在這台瀏覽器，下次打開同一頁會直接用，不會上傳。範例檔寫明不是你的角色。

2. 依這個帳號建議現在的 META 裝備

神器只建議你帳號裡有的。速度只拿你讀得到的裝備去比公開配裝的中位數；到不了就直說，不會把別人的面板寫成你的。主屬性與副屬性是 Epic7Tools 的建議，不是賽季頻率。沙盤用你穿上的數字。

先讀入帳號，才會對照賽季配裝。

3. 選角和戰況

選角和戰況只用你在主畫面點的人。不接遊戲畫面，不分享視窗，也不辨識。

沒有練度檔時不給選角。讀完後先等規則和先後手。選了就用：支援是靈魂燃燒技能傷害增加 15%，防禦是恢復和防護罩增加 30%，抵抗是效果抗性增加 50%，特殊是迴避減少 30%，無規則沒有額外效果。接著先給我方預禁，再點對方預禁。冠軍以上各 2 隻，冠軍以下各 1 隻。雙方都不能選被禁的角色。同時禁。發生在先後手之後、選角之前。當時只看得到規則和先後手，看不到對方預禁。有配裝、而且神器或專武已經知道但效果不在資料庫的項目，匯入後立刻列出來請貼截圖，不等對局，也不擋選角。我方只從有配裝的角色推薦，屬性全 0 不推薦。神器名稱有填時，專武和烙印照檔案判斷；三欄都空白才用預設並標未確認。你另外講的神器或專武蓋過檔案。預禁下面只寫名字和一句理由。每一手先看資訊結構：先選的第 1 選看 0 隻，第 2、3 選看對手 1、2，第 4、5 選看 1～4。後選的第 1、2 選看對手 1，第 3、4 選看 1～3，第 5 選看全部 5 隻。第 1、2 手只推熱門且穩定的，第 3、4 手才補協同，最後 1～2 手才針對。快速模式只寫局面確認、結論先看、當前階段的 Top 3 和信心度。深度模式才寫完整十一段。沒內容的段省略。結論 5 行內。不編 0～5 分，排名用候選名單的勝率與選用率。沒有名單就寫沒有收到候選名單。只引用資料卡和專武，沒有的標缺口並降信心。不寫沒上場的人。協同分數只引用名單上的數字。沒有匯入速度就不寫檔案速度。沒入庫的寫不確定，不編。點格子後，有配裝的角色直接點一下就填進該格，再點該格可以換。已經選上和預禁過的不再出現。對方選了某人，不因為我方有人克他，就把克他的人當這一手。技能和專武留在程式裡判斷，畫面不整段列出。配裝使用率是套裝組合的比例，不是神器使用率。五選完成才出 BAN。禁完才出戰鬥建議。沒有寫進資料的數字寫不確定。第 3 選是保護位核心。
