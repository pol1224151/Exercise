第七史詩　世界競技場

RTA 選角與回合顧問

先讀你的英雄和裝備，再對照這個賽季的配裝。世界競技場開打之後，才看畫面建議禁誰、選誰、放哪個技能、要不要燒魂。勝率是估計，不是必勝。

賽季：。遊戲版本：。技能倍率：。

1. 讀入帳號

先把角色和裝備放進來。還沒有這份帳號時，下面的配裝和畫面建議都不會開始。

  1. 打開 Fribbels Epic 7 Optimizer。在 Importer 開始掃描，進到大廳，停止掃描，存成 gear.txt，再按 Merge。
  2. 同一個 Importer 頁按 Save all optimizer data，存成 JSON。這份才有面板、神器和刻印。
  3. 回到這裡，選擇那個 JSON 或 gear.txt，或把內容貼進下面的框再按「用框裡的內容」。

還沒有帳號。

範例檔寫明不是你的角色。個人化的配裝和沙盤要等你的檔案。讀得到的欄位：英雄、套裝、速度、攻擊、生命、防禦、暴擊、暴擊傷害、效果命中、效果抗性、神器與等級。

2. 依這個帳號建議現在的 META 裝備

左邊是檔案裡的裝備，右邊是這個賽季天梯最常見的套裝和神器。主屬性與副屬性是 Epic7Tools 的建議，不是賽季頻率。沙盤不會把還沒穿上的裝備算進你的面板。

先讀入帳號，才會對照賽季配裝。

3. 競技場開始後才看畫面

請先完成第 1 步。帳號讀進來之後，等世界競技場開打，再分享遊戲視窗。

  1. 在 rta-advisor 執行 python3 server.py，用 Chrome 或 Edge 打開 http://127.0.0.1:8765/。
  2. 競技場畫面出現後，按「分享遊戲視窗」。在系統清單選第七史詩或模擬器那個視窗，不要選別的程式，然後按分享。
  3. 遊戲維持 16:9。語言用繁體中文即可，辨識看頭像不看文字。第一次把色框拖到我方五個頭像、對方五個頭像、預禁兩格、現在行動的頭像、底下三個技能鈕，再按「記住框線」。
  4. 按「開始判讀」。建議用的是你讀入的面板，加上英雄資料庫、Fribbels 倍率和這個賽季的模型。

畫面判讀還沒開。

競技場開始、畫面認出來之後，下一步會出現在這裡。

4. 更新英雄、倍率與賽季

Smilegate 出新英雄、平衡改版或新神器時，按這顆重新抓 Fribbels 的英雄資料庫和倍率，以及 Epic7RTAStats 的賽季模型。抓完上面會換成新的版本。

現在用的是已標版本的一份資料。按更新才會向來源要新的。

5. 對位

只列技能原文裡寫得出原因的對位。沒有寫進資料的機制不會編成對位。

    傷害公式沿用 Fribbels StatCalculator。沒有英雄資料庫、Fribbels 倍率，或這個賽季的模型時，不給建議。沒有讀入帳號時，不看畫面。
